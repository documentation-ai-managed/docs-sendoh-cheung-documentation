## Webhooks Overview

Webhooks enable real-time notifications for repository events, allowing you to build responsive integrations and automated workflows. Sendoh Cheung provides comprehensive webhook support for GitHub repositories, delivering event data to your configured endpoints as events occur. This guide covers webhook configuration, event types, and best practices for reliable webhook handling.

## Setting Up Webhooks

Creating webhooks is essential for building event-driven applications that respond to repository changes.

<Steps>
  <Step title="Define Endpoint" icon="link">
    Create an HTTPS endpoint that can receive and process webhook payloads.
  </Step>
  <Step title="Choose Events" icon="bell">
    Select which repository events you want to receive notifications for.
  </Step>
  <Step title="Configure Security" icon="shield">
    Set up webhook secrets for payload verification and secure transmission.
  </Step>
  <Step title="Register Webhook" icon="plus">
    Create the webhook through the API with your configuration.
  </Step>
  <Step title="Test Integration" icon="check">
    Send test events to verify your endpoint receives and processes payloads correctly.
  </Step>
</Steps>

<CodeGroup tabs="JavaScript,Python">
  ```javascript
const webhookConfig = {
  name: 'web',
  active: true,
  events: ['push', 'pull_request'],
  config: {
    url: 'https://your-app.com/webhook',
    content_type: 'json',
    secret: 'your-webhook-secret'
  }
};

const response = await fetch(`/api/repositories/${repoId}/hooks`, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${apiKey}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(webhookConfig)
});
const webhook = await response.json();
  ```
  ```python
import requests

webhook_config = {
    'name': 'web',
    'active': True,
    'events': ['push', 'pull_request'],
    'config': {
        'url': 'https://your-app.com/webhook',
        'content_type': 'json',
        'secret': 'your-webhook-secret'
    }
}

response = requests.post(
    f'/api/repositories/{repo_id}/hooks',
    headers={'Authorization': f'Bearer {api_key}'},
    json=webhook_config
)
webhook = response.json()
  ```
</CodeGroup>

## Managing Webhooks

The API provides tools for listing, updating, and removing webhooks as your needs change.

| Operation | Description |
|-----------|-------------|
| `GET /hooks` | List all webhooks for a repository |
| `PATCH /hooks/{id}` | Update webhook configuration |
| `DELETE /hooks/{id}` | Remove a webhook |
| `POST /hooks/{id}/test` | Send a test event to the webhook |

<Callout kind="tip">
  Regularly review and update your webhooks to ensure they remain active and configured correctly.
</Callout>

## Best Practices

Following webhook best practices helps ensure reliable, secure, and efficient event processing.

- Use HTTPS endpoints for all webhook URLs
- Implement proper error handling and logging
- Verify payload signatures for security
- Handle duplicate events gracefully
- Monitor webhook delivery and response times
- Keep webhook endpoints lightweight and responsive
