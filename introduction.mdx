## Getting Started

Sendoh Cheung Documentation provides a comprehensive platform for managing and generating documentation for GitHub repositories. Whether you're building APIs, libraries, or applications, our tool streamlines the process of creating professional, production-ready documentation with multiple MDX pages, OpenAPI specifications, and configuration files. This introduction will guide you through the key features and benefits that make Sendoh Cheung an essential tool for developers and teams.

## Key Features

Sendoh Cheung Documentation offers powerful features designed to enhance your documentation workflow. Our platform supports generating up to 9 files per project, including introduction pages, custom MDX content, changelog tracking, and API specifications. With support for diverse component types and intelligent content generation, you can create engaging, self-contained documentation that serves your users effectively.

<Tabs>
  <Tab title="MDX Pages" icon="code">
    Create rich MDX pages with 5-8 diverse components including cards, tabs, steps, and code examples.
  </Tab>
  <Tab title="API Documentation" icon="terminal">
    Generate comprehensive OpenAPI specifications for your APIs with detailed endpoint descriptions.
  </Tab>
  <Tab title="Configuration" icon="settings">
    Manage documentation structure with JSON configuration files for seamless navigation.
  </Tab>
</Tabs>
